The VC-A71P accepts standard VISCA commands over RS-232/RS-422 (9600–38400 bps) and VISCA-over-IP (UDP port 52381).

Connection

InterfaceDefault Setting
RS-232 / RS-4229600 bps, 8N1
VISCA-over-IPUDP 52381

Command Format

All commands begin with an address byte and end with the terminator FF. Example — camera address 1, power on:

8x 01 04 00 02 FF
