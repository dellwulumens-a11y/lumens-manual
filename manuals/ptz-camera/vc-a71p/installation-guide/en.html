This guide covers permanent mounting and system wiring for the VC-A71P. It is intended for installers, not end users.

Before You Start

  • Confirm the mounting surface can support at least 5x the camera's weight.
  • Plan cable runs for power, video and control before drilling any holes.
  • Record the camera's serial number and MAC address for your site documentation.

Mounting

The VC-A71P can be installed ceiling-up or desktop-standing using the supplied bracket. When mounting to a ceiling, use the included template to mark screw positions, and torque mounting screws to the bracket's rated value only — overtightening can deform the base plate.

Wiring

CableRecommendation
PowerUse the supplied 12V adapter, or PoE++ via the LAN port where supported
VideoHDMI runs under 10m; use 3G-SDI or an HDMI extender for longer distances
ControlShielded twisted pair for RS-232/RS-422, terminated at both ends

Network Setup

By default the camera obtains an address via DHCP. To assign a static IP, open the web control page at the camera's current address, go to Network Settings, and disable DHCP before entering a static address, subnet mask and gateway.

Installation Verification

After installation, confirm: video output matches the expected resolution and frame rate, pan/tilt movement is unobstructed across its full range, and all cable connections are strain-relieved.
