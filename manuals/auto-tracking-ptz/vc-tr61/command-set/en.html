In addition to standard VISCA PTZ commands, the VC-TR61 exposes a set of tracking-specific commands over RS-232/RS-422 and VISCA-over-IP (UDP port 52381).

Connection

InterfaceDefault Setting
RS-232 / RS-4229600 bps, 8N1
VISCA-over-IPUDP 52381

Command Format

Tracking commands use the vendor-specific command block, terminated with FF:

8x 01 7E 01 6D 0p FF
