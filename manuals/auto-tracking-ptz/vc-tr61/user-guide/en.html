The VC-TR61 is a 4K 30x auto-tracking PTZ camera that follows a presenter automatically using onboard AI, so a room can run camera-free.

Overview

VC-TR61 combines a 30x optical zoom block with an AI tracking engine. It can track a single presenter, hand off between multiple presets, or stay locked to a defined zone.

Package Contents

  • VC-TR61 camera unit
  • IR remote control
  • Power adapter
  • Ceiling/wall mount bracket

Setup & Connections

Connect HDMI, 3G-SDI or LAN as needed, then power on. Tracking mode is disabled by default on first boot and must be enabled from the OSD menu or web control page.

Basic Operation

Press the TRACK button on the remote to toggle auto-tracking on or off. While tracking is active, manual pan/tilt/zoom commands temporarily pause tracking for 5 seconds before it resumes.

Tracking accuracy depends on room lighting and the configured tracking zone — see the Installation Guide for placement recommendations.

Troubleshooting

If tracking drifts to the wrong person, reduce the tracking zone width in the web control page's Tracking Settings tab, and re-run the calibration wizard.
