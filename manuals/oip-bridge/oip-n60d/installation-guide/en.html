This guide covers rack installation and network configuration for the OIP-N60D 4K NDI decoder.

Before You Start

  • Confirm your NDI source and decoder are on the same subnet, or that routing between subnets is configured.
  • Reserve a static IP address for the decoder in your network plan.

Mounting

The OIP-N60D mounts in a standard 1U rack shelf, or can sit freestanding near the display it feeds. Ensure at least 2cm clearance around the ventilation openings.

Wiring

CableRecommendation
NetworkCat6 or better, gigabit switch recommended
Video outHDMI to display; use an active HDMI extender beyond 10m

Network Setup

Access the decoder's web interface at its DHCP-assigned address to select the NDI source to decode, or assign a static address under Network > IP Settings.

Installation Verification

Confirm the decoder locks onto the intended NDI source within a few seconds of power-up, and that video output resolution matches the display's native resolution.
