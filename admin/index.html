連接到 GitHub Repository

這個後台不會另外儲存帳號密碼——每次的新增／修改／刪除都是直接透過 GitHub API 對你的 repository 送出 commit，網站會沿用現有的 GitHub Pages 自動重新部署。

Token 只會存在這台電腦、這個瀏覽器的本機儲存空間，不會上傳到任何地方。請使用「Fine-grained personal access token」，只授權這一個 repository、Contents 權限設為 Read and write。

不知道怎麼申請 Token？點這裡看步驟
  1. 登入 GitHub，右上角頭像 → Settings
  2. 左側選單最下方 Developer settings
  3. Personal access tokens → Fine-grained tokens → Generate new token
  4. Resource owner 選擇這個 repository 所屬的帳號／組織
  5. Repository access 選 Only select repositories，選擇這個手冊網站的 repository
  6. Permissions → Repository permissions → Contents 設為 Read and write
  7. 設定好期限後點 Generate token，複製產生的 token（只會顯示這一次）貼到上面欄位
