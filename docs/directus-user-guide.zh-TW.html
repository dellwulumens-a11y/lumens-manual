Directus 後台使用手冊

這份文件說明如何登入 Lumens 手冊中心的 Directus 後台，以及如何管理「手冊（Manuals）」與「Q&A」這兩個你日常會用到的內容集合。若你要處理的是產品分類、手冊分類或系統架構等其他主題，請洽詢技術負責人。

01

後台介紹

Directus 是 Lumens 手冊中心目前使用的內容管理系統。手冊 PDF、線上內容、以及 Q&A 問答，都存放在這裡；你在這裡發布的內容會直接顯示在對外的手冊網站上。

如何登入

  1. 用瀏覽器開啟公司提供的 Directus 後台網址。
    目前為 https://lumens-manual-directus.zeabur.app；日後若換成公司網域（例如 cms.lumens.com.tw），會另行通知。
  2. 點選「使用 Google 登入」，選擇你的 @lumens.com.tw 公司信箱。
    系統只接受公司網域的信箱；個人 Gmail 或其他網域的帳號無法登入。
  3. 第一次登入會自動建立帳號並套用你的角色權限，不需要另外申請 GitHub 或資料庫帳號。

介面導覽

  • 左側選單「Content」：點開後會看到所有的資料集合（Collection），你會用到的是 manuals（手冊）與 qa_items（Q&A）。
  • 資料列表畫面：每個集合點進去是一張表格，每一列是一筆資料。右上角有「＋建立」按鈕、篩選（Filter）與搜尋（Search）。
  • 狀態欄位（Status）：每一筆手冊或 Q&A 都有狀態，決定它是否會出現在對外網站上：
    草稿 draft 尚未公開，只有後台看得到 審核中 in_review 僅 Q&A 使用，待覆核 已發布 published 對外公開，網站上看得到
  • 右側詳細面板：點開任一筆資料會在右側（或整頁）展開詳細欄位，改完記得按右上角「儲存」。

你的權限範圍

你的帳號屬於「TS Q&A Editor」角色，可以新增、修改、刪除 manuals 與 qa_items 的資料，以及上傳手冊檔案。你看不到、也不能修改使用者帳號、角色權限、或其他系統設定——這些是管理員才有的權限，如需調整請聯絡技術負責人。

02

手冊（Manuals）管理

「手冊」是使用者在網站上實際下載或閱讀的文件，例如某支手電筒的「使用手冊」PDF，或某台裝置的「快速指南」網頁內容。

資料關聯：一筆手冊屬於誰

新增手冊前，先確認這三件事，因為它們是每一筆手冊都必填的關聯欄位：

  • 屬於哪個產品（Product）——例如「P7 Pro」，產品本身又屬於某個產品分類。
  • 屬於哪個手冊類型（Manual Type）——例如「使用手冊」「快速指南」「保固卡」，這個清單是固定的，若找不到需要的類型請聯絡技術負責人新增。
  • 使用什麼語言（Language）——同一份手冊的不同語言版本，是各自獨立的一筆資料，不是同一筆資料的分頁。

新增手冊

手冊有三種呈現格式，新增前請先確定要用哪一種：

fragment 網頁內容

直接把內容以 HTML 貼進「Content」欄位，網站會把它嵌入手冊頁面顯示，不需要另外上傳檔案。

pdf 檔案

上傳一份 PDF，使用者在網站上點擊後會下載或直接開啟這份 PDF。

standalone 獨立頁面

上傳一份完整的獨立 HTML 頁面檔案，網站會直接連到這個檔案。

  1. 進入 Content → manuals，點右上角「＋建立」。
  2. 選擇 Product（產品）與 Type（手冊類型），並填入 Lang（語言）與 Title（標題）。
  3. 選擇 Format（格式）：fragment / pdf / standalone。
  4. 依格式填內容：
    fragment → 在 Content 欄位貼上內容。　pdf 或 standalone → 在 File 欄位點「上傳檔案」，選擇電腦裡的檔案。
  5. 將 Status 先設為 draft，儲存後自行預覽確認內容無誤。
  6. 確認沒問題後，回到這筆資料把 Status 改成 published 並再次儲存，正式對外公開。
小提醒先存成 draft 再檢查一次，比公開後才發現打錯字更省事——draft 狀態下一般使用者在網站上是看不到的。

修改手冊

  1. 在 manuals 列表用右上角「篩選」依 Product／Type／Lang 找到要改的那一筆，或用搜尋框輸入標題關鍵字。
  2. 點開該筆資料，修改需要的欄位（標題、內容、換一份檔案等）。
  3. 點右上角「儲存」。若這筆原本已是 published，修改儲存後會立即反映在對外網站上，請務必先確認內容再存檔。

刪除／下架手冊

注意刪除是永久性的、無法復原。如果只是想暫時讓某份手冊在網站上消失，把 Status 改成 draft 存檔即可，之後隨時可以再改回 published，不需要真的刪除重建。
  1. 確定真的要永久移除時，在 manuals 列表勾選該筆資料左側的核取方塊。
  2. 點右上角的垃圾桶／刪除圖示，跳出確認視窗後點「刪除」。

欄位對照表

欄位用途
product這份手冊屬於哪個產品（關聯到 products）
type手冊類型，例如使用手冊／快速指南（關聯到 manual_types）
lang語言版本
title顯示在網站上的手冊標題
formatfragment / pdf / standalone 三選一
content格式為 fragment 時填寫的 HTML 內容
file格式為 pdf 或 standalone 時上傳的檔案
statusdraft（草稿）或 published（已發布，才會對外顯示）
date_updated系統自動記錄，不需手動填寫
03

Q&A 管理

Q&A 是網站上的常見問答集，每一筆都需要同時填寫三種語言的問題與答案。

新增 Q&A

  1. 進入 Content → qa_items，點右上角「＋建立」。
  2. 選擇 Category（分類）。
  3. 依序填寫三種語言的問題與答案：question_en / answer_en、question_zh_cn / answer_zh_cn、question_zh_tw / answer_zh_tw。
    三種語言都要填，不能只填其中一種，否則其他語系的使用者會看不到這筆問答。
  4. 在 Products（適用產品）標籤欄位加入這筆問答適用的產品型號；若是通用問題（不限特定產品），可以留空。
  5. 視需要調整 Sort（排序）數字，數字越小顯示越前面。
  6. 將 Status 設為 draft 存檔預覽，確認無誤後改成 published 再次存檔即正式對外公開。

修改 Q&A

  1. 在 qa_items 列表用篩選（依 Category 或 Products）或搜尋框（輸入問題關鍵字）找到要改的那一筆。
  2. 點開修改需要的欄位——別忘了三種語言的內容通常要一起檢查是否都需要更新。
  3. 儲存。若已是 published，修改會立即反映在網站上。

刪除／下架 Q&A

注意與手冊相同，刪除無法復原。想暫時下架某筆問答，把 Status 改成 draft 即可，不需要真的刪除。
  1. 確定要永久移除時，在 qa_items 列表勾選該筆資料。
  2. 點刪除圖示並在確認視窗中確認。

欄位對照表

欄位用途
category問答所屬分類
question_en / zh_cn / zh_tw三種語言的問題文字，三個都要填
answer_en / zh_cn / zh_tw三種語言的答案文字，三個都要填
products適用的產品型號標籤，可複選或留空（代表通用）
sort顯示排序，數字越小越前面
statusdraft / in_review / published（唯有 published 對外公開）
date_updated系統自動記錄最後編輯時間，不需手動填寫
04

常見問題

我把狀態改成 published 了，為什麼網站上還是看不到？
確認瀏覽器網址是否有加上 ?cms=directus——目前網站預設仍讀取舊版的靜態資料，只有加上這個參數才會改讀 Directus 的內容。加過一次之後，同一台瀏覽器會記住這個設定。若已經加了還是看不到，稍等一分鐘再重新整理，或聯絡技術負責人確認。
可以先存草稿、確認沒問題後再公開嗎？
可以，而且建議這樣做。新增或大幅修改內容時，先把 Status 設為 draft 存檔，自行加 ?cms=directus 預覽確認排版與文字都正確，再把 Status 改成 published。
刪除跟改成 draft（草稿）有什麼不一樣？
改成 draft 只是讓它暫時不對外顯示，資料還在，隨時可以改回 published。刪除是把整筆資料永久移除，無法復原。除非確定以後都不會再用到，否則建議一律用「改成 draft」來下架內容。
Q&A 只填了中文，可以先發布嗎？
不建議。網站會依訪客選擇的語言分別讀取對應欄位，若某個語言欄位是空的，那個語系的使用者會看到空白內容。三種語言都填齊後再發布。
上傳的 PDF 有檔案大小限制嗎？
目前沒有在後台介面另外設定上限，但檔案仍會佔用伺服器儲存空間，請上傳前先用一般 PDF 壓縮工具處理過大的掃描檔（例如超過數十 MB 的檔案），避免不必要的空間浪費與載入變慢。
我可以自己新增產品或手冊類型嗎？
目前你的權限只開放編輯 manuals 與 qa_items。若需要新增產品、產品分類或手冊類型（例如出了新產品或新的文件類型），請聯絡技術負責人協助建立，建立好之後你就可以在新增手冊時選用。
兩個人同時在改同一筆資料會怎樣？
後面儲存的人會覆蓋前面的修改。若要同時處理同一批內容，建議先在群組內說一聲避免互相覆蓋，之後再各自處理不同筆資料。
